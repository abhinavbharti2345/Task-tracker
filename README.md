# 📝 Smart Task Tracker

A modern, minimal, and aesthetic task management web app built using **HTML, CSS, and Vanilla JavaScript**.  
The app focuses on clean UI, smooth interactions, and persistent task storage using the browser’s local storage.

---

## ✨ Features

- ➕ **Add Tasks**  
  Quickly add new tasks using the input field.

- ✅ **Mark Tasks as Completed**  
  Toggle tasks between completed and pending states.

- ❌ **Delete Tasks**  
  Remove tasks instantly with a single click.

- 🔍 **Task Filters**  
  View tasks based on their status:
  - All tasks
  - Pending tasks
  - Completed tasks

- 💾 **Persistent Storage**  
  Tasks are saved in `localStorage`, so they remain even after page reloads.

- 🎨 **Modern UI Design**
  - Glassmorphism effect
  - Smooth animations
  - Clean typography
  - Responsive layout

- ⚡ **Fast & Lightweight**  
  Built with plain JavaScript, no frameworks or libraries required.

---

## 🛠️ Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling, animations, glassmorphism  
- **JavaScript (ES6)** – Logic and interactivity  
- **LocalStorage API** – Data persistence
